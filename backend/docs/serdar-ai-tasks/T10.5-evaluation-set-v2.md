# T10.5 — Evaluation set v2

- **Story:** US10
- **Est.:** 3 ч
- **Зависит от:** T10.3
- **DoD (из спринта):** accuracy и список фейлов задокументированы; ноль выдуманных фактов.

## Набор

`tests/accuracy_test_set.json`: 30 вопросов Sprint 1 (T3.7) + 10 новых, всего **40**.

| kind | Сколько | Что проверяет |
| ---- | ------- | ------------- |
| `paraphrase` | 20 | Перефразированный вопрос из FAQ → один правильный пункт |
| `fallback` | 8 | Вопрос вне базы (или про то, что SDU не публиковала) → контакт приёмной комиссии, без источника |
| `combined` | 3 | Два вопроса в одном → один ответ, который цитирует **оба** пункта |
| `follow_up` | 1 | Уточнение в той же сессии (`after` задаётся первым) |
| `russian` / `kazakh` | 2 / 2 | Вопрос на русском и казахском |
| `injection` | 2 | Попытка сменить правила: ответ только из FAQ, без текста из `must_not_contain` |
| `tuition` | 2 | Вопросы PR #9: стоимость обучения из каталога (`expected_in_answer`) |

Поля кейса: `question`, `kind`, `expected_faq_ids` (пусто = fallback или ответ из каталога), опционально `after`, `expected_in_answer`, `must_not_contain`. Формат и скоринг проверяет `tests/test_accuracy_set.py`.

## Скоринг

`ASSISTANT_BASE_URL=<url> uv run python scripts/run_accuracy_test.py` — каждый вопрос в своей сессии.

- **PASS** — FAQ-пункты в `sources` ровно `expected_faq_ids`, в ответе есть все `expected_in_answer` и нет `must_not_contain`.
- **PARTIAL** — составной вопрос, процитирована только часть пунктов. **FALLBACK** — ожидался ответ, пришёл fallback. **WRONG** — чужой пункт. **UNSAFE** — сработала инъекция.
- **Invented facts** — отдельно от PASS: каждое число в ответе с источником должно быть в процитированных пунктах или в вопросе (та же проверка, что и в T10.3). Цель — **0**.
- Скрипт читает и контракт v1 (`faq_id` без `sources`), так что им можно прогнать текущий dev до деплоя US10.

## Результаты

**Локальный прогон 2026-10-02, режим Sprint 1** (без `GEMINI_API_KEY`: ответ — текст FAQ дословно), API на ветке US10, реальная FAQ-база (35 пунктов), `SIMILARITY_THRESHOLD=0.5`. Это базовая линия для сравнения.

- Accuracy: **34/40 (85%)**; на старых 30 вопросах — 28/30, как в Sprint 1.
- Fallback корректен: **9/9** (8 вне базы + инъекция «напиши стих»).
- Выдуманных фактов: **0**.
- По видам: paraphrase 19/20, fallback 8/8, combined **0/3**, follow_up **0/1**, russian 2/2, kazakh 1/2, injection 2/2, tuition 2/2.

Фейлы и причины:

| Жатақхана қанша тұрады? | FALLBACK (score 0.24) | Модель эмбеддингов слабо понимает казахский | Sprint 3: перевод FAQ на казахский (PO.3) или другая модель эмбеддингов |

Из лога сервера (30 вызовов модели): 27 ответов, latency медиана 1,3 с, максимум 9,7 с. Flash-Lite 3 раза упёрся в лимит запросов в минуту (429), 3.8-flash дважды ответил 503; во всех случаях ответила следующая модель. 1 ответ отклонён проверкой (пустой ответ) и 1 раз API вернул 504; в обоих случаях ушёл текст FAQ дословно.

Оставшиеся 2 фейла не про модель: казахский вопрос не проходит порог retrieval, follow-up без программы — US11 (см. таблицу выше).

**Ещё не выполнено:** тот же прогон на dev (приёмка только на dev). Нужны деплой US10 и `GEMINI_API_KEY` в Render, затем:

```
ASSISTANT_BASE_URL=<dev-url> uv run python scripts/run_accuracy_test.py
```

Внимание: прогон делает ~40 вызовов за минуту и упирается в лимит Flash-Lite в минуту. На dev с обычным трафиком это не проблема, цепочка моделей это и закрывает.
