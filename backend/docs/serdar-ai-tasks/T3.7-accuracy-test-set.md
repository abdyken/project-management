# T3.7 — Accuracy test set

- **Story:** US3
- **Est.:** 3 ч
- **Зависит от:** T3.4, T0.5 (дев-окружение)
- **Приоритет:** P2 — core
- **DoD (из спринта):** число accuracy и список фейлов задокументированы; все сценарии US3QATest прогнаны с записанным результатом.

## Что нужно сделать

Собрать тестовый набор из 10 типичных вопросов поступающих, прогнать его против сервиса, зафиксировать accuracy и фейлящиеся кейсы, выполнить сценарии US3QATest на дев-окружении.

## План реализации

1. **Набор вопросов (10 шт.):** составить из реальной FAQ-базы (T3.1) — покрыть разные категории (сроки, документы, язык обучения, стоимость и т.п.), плюс 2-3 вопроса заведомо вне базы (для проверки T3.4 fallback) и 1-2 "пограничных" по формулировке (перефразированные FAQ-вопросы, не дословные).
2. **Прогон:** скрипт, который бьёт в задеплоенный на дев-окружении эндпоинт `/api/assistant/ask` (не локально — так требует Product Owner acceptance rule), для каждого вопроса сравнивает полученный `faq_id` с ожидаемым.
3. **Метрика:** accuracy = доля вопросов, где вернулся правильный `faq_id` (или корректный fallback для вопросов вне базы).
4. **Документирование фейлов:** для каждого промаха — гипотеза причины (порог слишком высокий/низкий, несовпадение формулировки, проблема эмбеддинг-провайдера) и предложение (например, скорректировать `SIMILARITY_THRESHOLD` из T3.3/T3.4).
5. **US3QATest:** выполнить формальные Pass/Fail сценарии теста истории US3 на дев-окружении, зафиксировать результат письменно (как требует Product Owner acceptance rule — приёмка только на деплое, не локально).
6. Результаты (accuracy, список фейлов, факт прогона US3QATest) — зафиксировать в этом файле после выполнения.

## Что нужно от других

- **T0.5 (Nurmek):** рабочее дев-окружение, доступное по URL.
- **T3.4:** готовый fallback-путь, чтобы протестировать вопросы вне FAQ-базы.

## Результаты

**Локальный прогон 2026-09-24** против API в Docker (`python scripts/run_accuracy_test.py`), реальная FAQ-база из 35 пунктов (T3.1), локальная мультиязычная модель эмбеддингов, `SIMILARITY_THRESHOLD=0.5`. Набор: 20 перефразированных вопросов (в том числе на русском и казахском) и 6 вопросов вне базы — `tests/accuracy_test_set.json`.

- Accuracy: **24/26 (92%)**; вопросы вне базы: **6/6** получили fallback.
- Неверных ответов (чужой FAQ-пункт): **1** — «What must an international student bring when they arrive…» вернул faq-016 (взнос 200 USD) вместо faq-007 (документы по прибытии).
- Fallback вместо ответа: **1** — вопрос на казахском про общежитие (score 0.24): модель слабо понимает казахский, и система безопасно ответила контактами приёмной комиссии.
- Порог 0.5 выбран по этому набору: у вопросов вне базы максимум 0.26, у правильных ответов минимум 0.55.
- US3QATest на дев-окружении — **не выполнено**: дев-окружение (T0.5) ещё не развёрнуто. После деплоя: `ASSISTANT_BASE_URL=<dev-url> python scripts/run_accuracy_test.py`.
