## Контракт (черновик для согласования)

```
POST /api/assistant/ask
Content-Type: application/json

Request:
{
  "question": "string, 1-500 символов, обязательное",
  "session_id": "string (uuid), обязательное"
}

Response 200 OK:
{
  "answer": "string",
  "source_link": "string | null",
  "faq_id": "string | null",
  "similarity_score": "number (0-1)"
}

Response 400 Bad Request:
{ "error_code": "EMPTY_QUESTION" | "MISSING_SESSION_ID" | "QUESTION_TOO_LONG" }

Response 503 Service Unavailable:
{ "error_code": "ASSISTANT_UNAVAILABLE" }   // LLM/embedding-провайдер недоступен

Response 504 Gateway Timeout:
{ "error_code": "ASSISTANT_TIMEOUT" }       // ответ не уложился в latency budget
```

- **Latency budget:** 5 секунд end-to-end. Эндпоинт внутри себя таймаутит вызовы к провайдеру раньше (~4 c, см. T3.3/T0.7), чтобы гарантированно успеть вернуть 504 до того, как сработает 10-секундный таймаут виджета на фронте (T2.4).
- Below-threshold fallback (T3.4) возвращается как обычный `200 OK` с тем же форматом ответа — фронту не нужна отдельная ветка обработки.
