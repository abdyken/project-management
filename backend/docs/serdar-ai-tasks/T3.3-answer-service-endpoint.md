# T3.3 — Answer service endpoint

- **Story:** US3
- **Est.:** 5 ч
- **Зависит от:** T3.2
- **Приоритет:** P2 — core
- **DoD (из спринта):** эндпоинт отвечает на типовые вопросы поступающих совпадающим FAQ-пунктом и его source link; порог схожести настраиваемый.
- **Статус: реализовано и проверено локально** (curl-запросы, HTTP 200 с ожидаемым `faq_id`/`source_link`). Код: [`app/assistant/service.py`](../../app/assistant/service.py) (логика), [`app/assistant/router.py`](../../app/assistant/router.py) (HTTP-обёртка). Тесты: [`tests/test_service.py`](../../tests/test_service.py), [`tests/test_router.py`](../../tests/test_router.py).

## Что нужно сделать

Реализовать эндпоинт ассистента, принимающий `question` и `session_id` и возвращающий `answer`, `source link`, `faq_id` и similarity score, используя retrieval-индекс из T3.2 и настраиваемый порог схожести.

## План реализации

1. **Черновой контракт** (финализируется и подписывается с Daniyar в T3.5, но нужен уже здесь для реализации):
   ```
   POST /api/assistant/ask
   Request:  { "question": string, "session_id": string }
   Response: { "answer": string, "source_link": string, "faq_id": string, "similarity_score": number }
   ```
2. **Логика обработки:**
   - посчитать эмбеддинг входящего вопроса (провайдер T0.7);
   - найти top-1 (и, возможно, top-3 для логов/отладки) по индексу T3.2;
   - если `similarity_score >= SIMILARITY_THRESHOLD` → сформировать ответ на основе `faq.answer` (текст ответа — из FAQ, без свободной генерации фактов, чтобы не подставлять источник, которого нет; LLM может использоваться только для перефразирования, не для добавления информации);
   - если ниже порога → делегировать в fallback-путь (T3.4), эндпоинт не должен сам "придумывать" ответ.
3. **Конфигурация:** `SIMILARITY_THRESHOLD` — переменная окружения, дефолтное значение подбирается и уточняется по результатам T3.7.
4. **Где живёт код:** внутри backend-проекта, в модуле `assistant`, который создаётся структурой из T0.3 (Dinmukhamed). Согласовать язык/фреймворк по решению T0.1 — этот план не привязывается к конкретному языку, только к контракту и логике.
5. **Таймауты:** внутренний таймаут вызова LLM/embedding-провайдера ~4 c, чтобы уложиться в 5-секундный latency budget из T3.5 и не зависеть только от 10-секундного таймаута виджета (T2.4, Daniyar).
6. **Заготовка под логирование** вопрос/ответ — не реализуется в этой итерации (перенесено в Iteration 3 вместе с US9), но стоит оставить один явный вызов-заглушку/интерфейс, чтобы не переписывать структуру позже.
