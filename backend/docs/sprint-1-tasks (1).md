# Iteration 1 (Sprint 1) — task breakdown, greenfield start

Starting point: nothing is implemented yet. There is no repository, no portal, no database, no program data and no FAQ base. Everything below is built from zero inside this iteration, therefore the iteration starts with a foundation block (T0.x) before any user story task can begin.

Sprint goal: one deployed demo environment where a prospective student can find a study program, open the chat window, get an FAQ-based answer with its source link, and ask which documents are required for the chosen program.

Scope assumption for iteration 1: a thin but complete vertical slice - about 10-15 real study programs and about 30 official FAQ items, demo quality, one dev environment. Volume, performance and comfort features are planned for iteration 2+ (see the 'moved out' block under the table).

Product Owner acceptance rule: a task is Done only when its Definition of Done is met; a story is accepted only when its US\*QATest scenarios (Pass and Fail cases) are executed and pass on the deployed dev environment, not on a local machine.

All tasks start at status **To Do**, deadline **18.09.2026**.
