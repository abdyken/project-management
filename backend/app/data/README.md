# Placeholder data

These fixtures let the `assistant` module run and be tested **before** the
real data from other tasks exists. Replace them once the owning task ships —
do not treat them as source of truth.

- `faq_sample.json` — stand-in for **T3.1** (Askhat, "Collect and clean the
  FAQ base"). Demo content only, not reviewed by the admissions office. Swap
  for the real T3.1 export (same field shape: `faq_id, question, answer,
  category, source_link, last_update`) and re-run `scripts/reindex_faq.py`.
- `faq_index.json` — generated by `scripts/reindex_faq.py`, git-ignored.
- `programs_sample.json` — stand-in for **T1.1/T1.2** (Dinmukhamed/Askhat,
  program catalogue) used only by `catalog_client.py` until the real
  `/api/programs` endpoint (T1.3) is deployed.
